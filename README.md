# Чайный клуб — бронирование в Telegram (пилот)

Идея: настраиваемая система бронирования и заказов для малого бизнеса, Telegram — один из каналов.
Первый реальный кейс — чайный клуб с несколькими «полянками», столами и общим столом для мероприятий.

## Статус
Этап 0: дизайн-прототип клиентской брони. Бэкенда пока нет.

## Прототип
Откройте `prototype/index.html` в браузере (без сборки и зависимостей). Тема переключается кнопкой «ТЕМА»
или параметром `?theme=paper` / `?theme=dark`.

В прототипе данные заведения (места, вместимость, часы работы, занятость) — демонстрационные.

## Что заложено как правила (будут настраиваться, а не вшиты в код)
- Бронь на 1–3 часа, без предоплаты.
- Полянки на 1–8 гостей, столы на двоих (втроём теснее).
- Большой стол — для мероприятий, не бронируется как обычное место.
