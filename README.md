# Чайный клуб — бронирование в Telegram (пилот)

Идея: настраиваемая система бронирования и заказов для малого бизнеса, Telegram — один из каналов.
Первый реальный кейс — чайный клуб с несколькими «полянками», столами и общим столом для мероприятий.

## Статус
Этап 0: дизайн-прототип клиентской брони. Бэкенда пока нет.

## Прототип
Откройте `prototype/index.html` в браузере (без сборки и зависимостей).
Тему переключает кнопка «ТЕМА» или параметр `?theme=walnut` / `?theme=paper`; `?guests=7` задаёт число гостей.
Скриншоты — в `prototype/screenshots/`.

Визуальное направление: старый китайский чайный дом — дерево, бамбуковая зелень, бумага, красная печать,
пиксельная карта зала. Данные заведения (места, занятость, часы работы) в прототипе демонстрационные.

## План зала (со слов заказчика)
- Три отдельные полянки: две малые (комфортно 3, максимум 4) и большая (комфортно 6, максимум 8).
- Стол в европейском стиле в зале (2, максимум 3).
- Закрытый стол в отдельной комнатке, как мини-переговорка (2, максимум 3).
- Большой общий стол — для мероприятий, как обычное место не бронируется.
- Не бронируются: магазин, склад, коридор с туалетом.

## Правила (будут настраиваться, а не вшиты в код)
- Бронь на 1–3 часа, без предоплаты.
- У каждого места две вместимости: комфортная и максимальная («тесновато»).
